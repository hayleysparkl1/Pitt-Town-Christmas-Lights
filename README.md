# Pitt Town Christmas Lights Trail

A community project for sharing Christmas lights around Pitt Town, NSW.

The planned website will let residents submit decorated homes and let visitors
choose stops for a Christmas lights trail they can open in Google Maps.

## Project status

First prototype: a static landing page. Address submissions, saved trails, and
map links have not been added yet.

## Run locally

Open `index.html` in a web browser.
